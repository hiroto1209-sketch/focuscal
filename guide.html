USER GUIDE

FocusCal

予定を終わらせるたび、画面がお祝いしてくれるカレンダー。
「続かない」を、楽しさで解決するために作りました。

はじめかた 基本操作 お祝い機能 語学モード 筋トレ記録 テーマ 隠し要素 よくある質問

📲 はじめかた

ホーム画面に置くと、普通のアプリのように使えます

🍎 iPhone（Safariで開いてください）

  1. アプリのURLを Safari で開く
  2. 画面下の共有ボタン（□に↑）をタップ
  3. 「ホーム画面に追加」を選ぶ
  4. 右上の「追加」をタップ → 完成！

🤖 Android（Chrome）

  1. アプリのURLを Chrome で開く
  2. 右上のメニュー（⋮）をタップ
  3. 「ホーム画面に追加」を選ぶ
DATA

データはこの端末の中だけに保存されます

アカウント登録もログインも不要。入力した予定は誰にも送信されず、あなたのスマホの中だけに残ります。

Safariの履歴やサイトデータを消すと予定も消えます。下の「バックアップ」で定期的に保存しておくと安心です。
BACKUP

💾 バックアップと復元

設定（⚙）の一番上にあります。「バックアップを保存」を押すと、予定・筋トレ記録・メモ・設定がまとめて1つのファイルになって保存されます。

機種変更したときや、うっかりデータを消してしまったときは、「復元する」からそのファイルを選ぶだけで元通りです。

月に一度の保存がおすすめ。30日以上経つと設定ボタンに金色の印が出てお知らせします。

👆 基本操作

覚えるのは「タップ」と「長押し」の2つだけ
👆
日付をタップ
その日の予定入力画面がすぐ開きます。タイトルを入れて「保存する」だけでOK。
✋
日付を長押し（0.5秒）
色とエフェクトを選べます。楽しみな予定を光らせておくと、カウントダウンが始まります。
↔️
左右にスワイプ
月を移動。上部の「今日」ボタンでいつでも今月に戻れます。
📆
「2026」の年表示をタップ
2022年〜2030年まで切り替えられます（横にスクロールできます）。年ごとに別々の予定として保存されます。「今日」ボタンでいつでも今日の年月に戻れます。
⭕️
予定の ○ をタップ
完了！お祝いコメントが流れます。ここがこのアプリの主役です。
✏️
予定そのものをタップ
内容を編集できます。時間はバーを指でスライドして直感的に設定。
↩️
上部の ↩ / ↪
間違えても何度でも取り消し・やり直しができます。安心して触ってください。
↗
予定の「↗」をタップ
その予定を友達に送れます。相手がリンクを開くと、自分のカレンダーに取り込めます。
📋
画面下のバーを上にスワイプ
今日から年末までの予定を一覧できます。
BOTTOM

カレンダーの下も使えます

今日のフォーカス：今日やることだけを表示。ここからも○タップで完了できます。
記念日カウンター：付き合った日、施術を受けた日などから「何日目」かを自動で数え続けます。タップすると内容を編集・削除できます。
クイックメモ：予定にするほどでもない思いつきを書き捨てる場所。

3つのパネルはどれかを長押しすると並び替えモードになり、好きな順番に入れ替えられます。

🎉 お祝い機能

このアプリのいちばん大事なところ

予定を完了すると画面が沸きます

ニコニコ動画のようにコメントが流れ、光が弾け、音が鳴ります。「終わらせると気持ちいい」を作るための仕組みです。

🎉ボタンでいつでもお祝い

画面右下の「✦」ボタンを押すと3つの機能が飛び出します。その中の🎉を押せば、予定がなくてもお祝いされます。

  • 🎉を長押しすると……何かが起きます（隠し要素の項目へ）

コメントは自由に書き換えられます

設定（⚙）→「お祝いコメント」から、自分が言われたい言葉に変更できます。友達の名前を入れるのもおすすめ。

  • 量も「控えめ / ふつう / お祭り / 大狂乱」から選べます

🌏 語学モード

達成の瞬間に、英語や中国語が流れます

設定から言語を切り替えるだけ

⚙ →「お祝いコメントの言語」で 日本語 / 英語 / 中国語 を選択。英語なら和訳つき、中国語ならピンイン＋和訳つきで流れ、ネイティブ音声も再生されます。

  • ナチュラル（教科書的）とスラング（リアルな口語）を切替可能
  • 収録フレーズは全144個（英語80／中国語64・ナチュラル＆スラング両対応）。自分のフレーズも追加できます

📖 フレーズ帳（右下の「✦」→ 本のボタン）

収録フレーズを一覧で勉強できます。

  • 発音記号・ピンイン・日本語訳つき
  • タップすると音声が流れる（🐢でゆっくり再生）
  • ☆でお気に入り登録 → 自分だけの復習リストに
  • 🔍で検索も可能

💪 筋トレ記録

鍛えた部位が光る、人体ヒートマップ

使い方は3ステップ

  • 右下の「✦」→ 💪ボタンを押す
  • 人体図の鍛えた部位をタップ（前面・背面あり）
  • セット数を選んで「記録する」→ お祝いが流れます

種目名・回数・重量はすべて任意。面倒なら部位とセット数だけでOKです。

鍛えるほど身体が光ります

その月に鍛えた回数が多いほど、その部位の色が濃くなり、4回以上でネオンのように発光します。「今月は脚が真っ暗だな」が一目でわかります。

  • 7部位すべて鍛えると「🏆フルボディ達成」
  • 筋トレした日はカレンダーに💪マークが付きます（設定でオフ可）

🤫 隠し要素

タップするとネタバレが表示されます

見つけた人だけの機能が3つあります

「今日」ボタンを7回連打 → 隠しテーマ「🌌ギャラクシー」が解放。星が瞬き、流れ星が落ち、オーロラが漂う特別な画面になります。
🎉ボタンを長押し → 「MEGA FESTIVAL」発動。40連コメントと四方からの光で画面が埋め尽くされます。
上部の「◯年 ◯月」を長押し → 🎨背景カラーが解放。漆黒・ネイビー・深緑・ワインなど9種類から選べるようになります。

❓ よくある質問

無料ですか？

はい、完全無料です。広告もありません。

予定は他人に見られませんか？

見られません。データはあなたの端末内にのみ保存され、サーバーには一切送信されていません。

間違えて予定を消してしまいました

画面上部の「↩」ボタンで元に戻せます。何度でも遡れます（最大100回分）。

音が出ないのですが

端末がマナーモードだと鳴らない場合があります。また設定（⚙）で「🔇音声なし」になっていないか確認してください。

通知は来ますか？

現在、通知機能はありません。ホーム画面に置いて、開いた時に確認する使い方を想定しています。

週の始まりを月曜にしたい

設定（⚙）→「週の始まり」で切り替えられます。

機種変更したらどうなりますか？

設定（⚙）から「バックアップを保存」でファイルを書き出し、新しい端末で「復元する」から読み込めば、すべて引き継げます。
